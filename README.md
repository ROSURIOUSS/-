# Sandustry Resource Bot — разработка

**Не готовый мод. Не устанавливать в папку игры.**

Цель: бот с выбором ресурса, точкой доставки и большим регулируемым инвентарём для Sandustry 0.6.0 PC Game Pass.

## Сделано

- Изучены предоставленные файлы игры; выявлено ограничение загрузки модов на Game Pass.
- Независимый от движка контроллер: добыча → доставка → разгрузка.
- Вместимость по умолчанию 10 000 единиц, допустимо 1–1 000 000.
- Ограничение работы за такт; блокировка разгрузки не уничтожает груз.
- Остановка/возобновление, проверка настроек, копия состояния.
- Автоматические тесты сохранности количества и свойств ресурсов на искусственном адаптере.

## Пока отсутствует

Загрузчик для Game Pass, адаптер мира, настоящий движущийся бот, интерфейс, выбор точки мышью, интеграция сохранений. Тесты контроллера **не подтверждают совместимость с игрой**.

## Проверка

Node.js 18+; без зависимостей:

```sh
npm test
```

Подробности: [проверка совместимости](docs/compatibility-0.6.0.md).

Файлы игры и сохранения пользователя не входят в репозиторий.

## Обновление контроллера

- Настройка вместимости при остановленном боте; нельзя уменьшить её ниже текущего груза.
- `ResourceBot.restore(adapter, snapshot, {worldId})` проверяет формат и принадлежность миру; восстановленный бот остановлен.
- Снимок проходит JSON round-trip; интеграции сохранений с игрой ещё нет.
- Защита от повторного входа в `tick` и остановка при ошибке адаптера.
- Один такт выполняет только одну фазу цикла.
- Read-only аудит исходных файлов: `node tools/audit-game.mjs <directory>`.

## Экспериментальная проверка загрузки панели

В `diagnostic/` добавлена отдельная HTML-панель и Windows-обёртка установщика. Это **не бот**, а тест подключения на конкретной присланной сборке 0.6.0. Контроллер ресурсов к ней не подключён.

Установщик `tools/asar-probe.mjs` проверяет SHA-256 main/preload/HTML, сохраняет полный оригинал и меняет только HTML-страницу внутри ASAR. Есть проверяемый откат; изменённая или обновлённая игра не затирается. Лицензирование и ограничения целостности не отключаются. Запуск игры после такого изменения может быть отклонён платформой.

Инструкция и ограничения: [тест панели](diagnostic/ИНСТРУКЦИЯ.md).

## Отдельная правка копии сохранения

`tools/add-oxyblobs.py` — автономный редактор экспорта 0.6.0: проверяет MD5 исходника, ищет три свободных места под естественными потолками в радиусе поиска 150 клеток от игрока, исключает клетки построек и запретных зон, добавляет записи `gulper` и создаёт отдельный ID мира. Отказывается перезаписывать выходной файл или исходник. До выдачи результата полностью сравнивает остальные данные и проверяет обратную распаковку. Не является проверкой импорта в работающую игру.

```sh
python -m unittest discover -s test -p 'test_save_editor.py' -v
```

Экспорт пользователя не публикуется в Git. Редактор не связан с тестовым установщиком панели.
