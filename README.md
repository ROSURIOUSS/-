# Биосфера 0.10 — индивидуальные нейросети с обучением при жизни

**Настольная программа Godot + Python. Не сайт, не Electron и не веб-обёртка.** Нет браузера, HTTP-сервера, портов, облачных API или сетевых ключей.

Объёмная планета с океанами, рельефом, облаками и живой экосистемой. Колёсиком можно приблизиться от орбиты к отдельному организму. **Это одни и те же существа и одно состояние мира на всех масштабах**, а не отдельные декоративные сцены.

Ориентиры — наблюдение за автономным миром как в The Universim, наследование как в The Sapling и клеточный масштаб как в Spore. Это ещё **не готовый аналог этих игр или Underworld из SAO**: цивилизаций, сознательных NPC и перехода от клетки к разумному виду пока нет.

## Запустить у себя

Требуются **Godot 4.5+** (обычная версия, .NET не нужен) и **Python 3.11+**. Само ядро — только стандартная библиотека, без PyTorch/TensorFlow и плагинов Python для Godot. Свежий Python поддерживается без привязки к бинарным ML-пакетам.

1. Скачай актуальные файлы проекта целиком.
2. Импортируй **`godot/project.godot`** в менеджере проектов Godot.
3. Нажми **F5**. Откроется обычное окно программы, ядро запустится автоматически.

**Важно: брать нужно обновлённую папку `godot` целиком**, включая `python_core.zip`, `shaders/` и скрипты. Замены только `project.godot` недостаточно.

### Версия Godot

Начиная с 0.8 нужен **Godot 4.5 или новее**. В Godot 4.4.1 на Linux обнаружена ошибка `OS.execute_with_pipe`: закрытие stderr-канала первого процесса закрывает stdin родителя и ломает следующий запуск ядра. В исходниках 4.5 это исправлено. При старом движке программа теперь показывает сообщение об обновлении вместо неработающего перезапуска. В CI используется 4.5.2.

### Исправление ошибки «Не найдено Python-ядро»

В `godot/python_core.zip` теперь лежит компактная встроенная копия Python-исходников. Если программа не использует отдельное упакованное ядро, она распаковывает эту копию в **пользовательский каталог Godot** и запускает её автоматически. Можно импортировать даже одну полную папку `godot`, без соседней папки `simulator`.

Архив проверяется по SHA-256: новая версия распаковывается отдельно и не подхватывает старую копию. Системные каталоги и папка установки не требуют записи. Встроенная версия имеет приоритет над случайно оставшимися старыми исходниками рядом. Если архив отсутствует, дополнительно проверяются абсолютные пути к соседнему `simulator`, локальному `simulator` и `core/simulator`. При ошибке показываются проверенные пути.

Это **встроенные исходники**, не сам интерпретатор: для запуска из редактора установленный Python всё ещё нужен. Windows: проверяются `py -3`, затем `python`; Linux/macOS: `python3`, затем `python`. В собранном варианте с `--bundle-python` интерпретатор уже включён.

### Без открытия редактора

```powershell
# Windows, если Godot находится в PATH
start_game.bat
# Или явно укажи портативный редактор:
py -3 tools/launch.py --godot "C:\Programs\Godot\Godot.exe"
```

```bash
# Linux
./start_game.sh
# Или:
python3 tools/launch.py --godot /path/to/Godot
```

`Godot*.exe` также можно положить в корень репозитория. Запускатель автоматически обновляет архив ядра и передаёт путь к тому Python, которым запущен сам.

## Автосохранение и восстановление

В левой панели появился раздел **«Прогресс / автокопии»**. По умолчанию автосохранение включено с интервалом **60 секунд реального времени**; можно выбрать 30 / 60 / 180 секунд или отключить его. Настройки сохраняются в `user://preferences.cfg` и не требуют сети.

- **Три слота** `slot-1.biosphere` / `slot-2.biosphere` / `slot-3.biosphere` находятся в `user://worlds/autosaves`. Новая подтверждённая копия заменяет самую старую исправную, либо занимает свободный/повреждённый слот. Это общие последние три копии программы, **не отдельный архив каждого мира**. После перехода к новому миру старые копии постепенно заменяются.
- Порядок определяется возрастающим номером записи, **не временем изменения файла**. Неверные часы не переставляют копии. В интерфейсе показывается сохранённое UTC-время, день, численность; при подтверждении — также семя.
- Автоматическая запись делается после изменений, не чаще выбранного интервала. Неизменяющийся мир на паузе не переписывается по кругу. Запись откладывается, пока идёт мазок/ответ кисти, открыт файловый диалог или подтверждение выхода.
- **«Сделать автокопию сейчас»** создаёт контрольную копию по явному запросу, даже если мир не изменился. Ручные «Сохранить / Загрузить» по-прежнему работают отдельно.
- Список позволяет выбрать одну из трёх исправных копий и **подтвердить восстановление**. Мир не заменяется до полного чтения и проверки файла. Восстановление всегда включает паузу и очищает старую отмену кисти; сама запись автокопии отмену не очищает.

При запуске ядро сначала ставит начальный мир на паузу и проверяет копии. Если они есть, программа **предлагает восстановить прогресс или начать новый мир**. До выбора нельзя запустить симуляцию, рисовать кистью или автоматически перезаписать копии. Молча выбирать восстановление программа не должна. Если чтение каталога в целом не удалось, автоматическая запись отключается для текущего сеанса, а мир остаётся на паузе до решения пользователя.

Повреждённый, обрезанный, слишком большой или не прошедший проверку балансов файл пропускается с предупреждением. Если последний слот повреждён, доступна предыдущая исправная копия. **«Обновить копии»** перечитывает список, в том числе в диалоге восстановления. Если другой экземпляр уже заменил выбранный слот, номер записи проверяется повторно: программа не подменяет выбранный мир другой копией.

Файлы пишутся через временный файл, `flush`/`fsync` и атомарную замену. При ошибке записи до замены прежний слот остаётся целым; другие слоты не ротируются цепочкой переименований. Записанная копия проверяется повторным чтением. Межпроцессная блокировка каталога препятствует одновременной записи двумя экземплярами; после падения процесса блокировка освобождается ОС, отдельный старый `.write.lock` не блокирует программу навсегда. Ошибка автокопии отображается и не вызывает непрерывный цикл записи. При ошибке самого расчёта новые автокопии не заменяют прежние исправные.

Это локальные резервные копии, **не облако и не гарантия от поломки накопителя**. При аварии может потеряться прогресс после последней успешной записи. После принудительного завершения в каталоге иногда остаётся незавершённый временный файл; он не предлагается как исправная копия. Важные миры сохраняй вручную в отдельные файлы и при необходимости копируй на другой носитель. Текущий формат мира — **v8**, с чтением v1–v7; версия приложения 0.10 и приватный IPC-протокол 10 — отдельные номера.

## Песочница: вмешивайся, затем наблюдай последствия

Вверху левой панели — **«Песочница / инструменты»**. По умолчанию включено безопасное **наблюдение**, а не разрушительная кисть. В режиме наблюдения левый щелчок выбирает существо; с выбранной кистью — меняет мир.

| Инструмент | Что действительно изменяется |
|---|---|
| Заселить травоядных / хищников | Новые организмы с индивидуальными сетями, геномами и ID. Это основатели, не естественные рождения |
| Озеленить | Запас растительной пищи, покров и немного плодородия |
| Удобрить | Почва и часть пищевого запаса |
| Нагреть / охладить | Локальная температурная поправка; влияет на рост растений, покров, нагрузку на организмы и их нейросенсоры |
| Поднять / опустить сушу | Настоящая высота участков, береговая линия и доступная суша |
| Иссушить | Уменьшение влаги почвы, пищи, растительного покрова и плодородия |
| Вызвать дождь | Локальные осадки и увлажнение суши; дождь допустим и над океаном |
| Лечить и кормить | Реальные здоровье и энергия существ в радиусе |
| Убрать организмы | Удаление живых существ с отдельной причиной смерти «вмешательство» |

Выбери инструмент, **радиус 0.75–8 участков**, силу 0.1–1 и число вводимых организмов 1–30 за касание. Кольцо на поверхности показывает область кисти. **ЛКМ или удержание с перемещением** наносят мазок; правая кнопка по-прежнему вращает камеру. Касания отправляются последовательно, без очереди из сотен операций. Для рельефа частота ниже, поскольку перестраивается 3D-сетка. Радиус измеряется в координатах экологической сетки: около полюсов круг геометрически искажается, это не геодезическое расстояние.

**Esc — обратно к наблюдению. Ctrl+Z — отменить последний мазок. N — один шаг и пауза**, независимо от выбранного ускорения. Кисти работают и на паузе. Локальная температурная поправка ограничена ±40 °C и постепенно затухает с характерным временем 120 игровых дней, только когда идёт модельное время. Слой «Температура» и карточка организма учитывают нагрев/охлаждение; общая температура в шапке остаётся сезонной базовой температурой планеты.

Отмена — **один контрольный снимок всего мира перед началом непрерывного мазка**, а не только обратное изменение краски. Она возвращает время, случайный генератор, организмы, их память, среду, историю и статистику. **Автономные события после начала мазка тоже отменяются; после восстановления включается пауза.** Следующий мазок заменяет этот снимок. Повторной отмены и redo нет. Снимок отмены не записывается в сохранение; успешная загрузка или создание мира его очищают. Ошибочная операция не должна уничтожать предыдущую отмену.

При затоплении влага получает полное океаническое значение; погибшие считаются вмешательством, а не охотой или голодом; пища, останки, почва и покров затопленных участков обнуляются. Новая суша получает небольшой стартовый запас почвы и растений, а её влага инициализируется по климату. Последний участок суши затопить нельзя. Заселение и озеленение океана запрещены; океан можно нагревать и поднимать из воды. Общий предел остаётся 500 организмов. Для повторного заселения вымершего мира не нужно создавать новую планету.

Это **экологическая god-game песочница**, не физический симулятор песка/частиц. Магмы, взрывов, строительства городов и цивилизаций пока нет. Без вмешательства мир продолжает жить автономно.

## Погода и водный цикл

Погода теперь рассчитывается **в Python-модели**, а не только рисуется поверх планеты:

- Движущиеся фронты осадков зависят от семени, времени, широты, долготы и параметра осадков мира. Долгота замкнута, фронт не обрывается на шве. Расчёт не расходует RNG существ и не меняется от частоты запросов состояния.
- Каждый участок суши хранит **влажность почвы 0–1**. Осадки пополняют её; жара усиливает испарение, растительный покров сдерживает потерю влаги, высота влияет на дренаж, а плодородие — на впитывание.
- Влажность влияет на восстановление пищи, покрова, деградацию почвы и биомы. Поэтому засуха меняет доступные ресурсы для существ с их реальными сетями. Животные пока не пьют и не имеют отдельной нейросенсорики дождя: влияние идёт через среду и пищу.
- Нагрев кистью усиливает испарение при следующих шагах. **«Иссушить»** сразу уменьшает влагу суши, но не удаляет атмосферу: естественный дождь может снова увлажнить этот участок.
- **«Вызвать дождь»** добавляет местную надбавку к осадкам и сразу увлажняет землю. Надбавка ограничена 0–1 и затухает с характерным временем **3 игровых дня**, только при продвижении симуляции. Суммарные осадки ограничены 1.

В меню слоёв появились **«Влажность»** и **«Осадки»**. Над картой — средние осадки и влажность **только по суше**, а также доля засушливых участков (влага ниже 18%). Осадки в процентах — **относительная интенсивность**, не вероятность дождя, не доля площади и не миллиметры в сутки. В HUD показывается участок под центром камеры, в карточке — участок самого организма.

Облачная оболочка использует ту же карту осадков. На региональном и клеточном масштабе отображаются дождевые штрихи около камеры, только в участках с осадками; максимум 256 одновременно. Рисунок облаков и форма капель условны, не отдельные физические облака и капли. На паузе фиксируются модельная погода, влага, затухание надбавки и анимация дождя. Другие косметические эффекты могут продолжаться. При засухе растительный покров отображается более бурым.

Флажок **«Облака и дождь»** отключает только графику для удобства или производительности. Расчёт погоды и последствия для экологии продолжаются. Погода и влага входят в сохранение/отмену; атмосферный фронт восстанавливается из времени и семени, ручная надбавка и запас влаги сохраняются явно.

Это **упрощённый водный баланс почвы с заданными атмосферными фронтами**, не замкнутая гидрологическая система: молекулярного переноса, сохранения общей массы воды, рек, озёр, паводков, снежного покрова и CFD здесь пока нет. У океана влага всегда 1 как служебный полный резервуар; это не почва под водой.

## Наследуемое тело и родственные линии

В карточке организма теперь есть **вытянутость, панцирь, подвижность и ID родственной линии**. Вытянутость и панцирь — настоящие наследуемые числовые гены, а не случайный декоративный облик:

- **Вытянутость 0.65–1.8** меняет пропорции 3D-тела. Более вытянутая форма увеличивает подвижность, но повышает энергетическую стоимость команды движения. Без панциря объём отображаемого тела при изменении вытянутости приблизительно сохраняется.
- **Панцирь 0–1** утолщает отображаемое тело и усиливает сегментированный рисунок оболочки. Он уменьшает урон хищника, но снижает подвижность и требует энергии даже без движения. Максимальный панцирь не даёт бессмертия.
- **Подвижность** = ген скорости × √вытянутости / (1 + 0.45 × панцирь). Это множитель смещения, не измеренная текущая скорость. Урон делится на (1 + 1.6 × панцирь жертвы). Существуют и остальные расходы энергии — размер, обзор, температура, возраст и движение.
- При рождении гены наследуются и могут мутировать с вероятностью из параметров мира. При нулевой мутации форма и панцирь сохраняются. Раны, текущая память и жизненная статистика не наследуются. Веса сети остаются отдельным наследуемым геномом.

Открой **«Линии и наследование»** в левой панели. Список показывает реальные живые родственные группы, их численность и максимальное поколение; подсказка строки — средние признаки. Группы отсортированы по численности, затем по ID, без выдуманных названий видов. Щелчок по строке включает наблюдение, приближает к представителю и включает слежение. Родственники выделяются тёплым цветом, остальные приглушаются. На орбите подсвечиваются занятые семьёй участки, не дополнительные существа.

С включённым **«Следить за родственной линией»** после смерти выбранного существа выбирается живой родственник: сначала наибольшее поколение, затем число детей, затем меньший ID. Если вся линия исчезла, камера не перескакивает к чужой. Ручное заселение создаёт новых основателей с отдельными линиями; оно не считается естественным видообразованием.

**Линия — не биологический вид**, не социальная группа и не полный архив всех умерших предков. У новых миров наследуется ID основателя, даже когда тот умер. У старых файлов можно восстановить только связи по имеющимся записям: если предок отсутствует, используется известный родитель-якорь, а линия помечается **`?` / «частичная»**. Неизвестные общие предки не угадываются. Форма сейчас — параметрическое клеточное тело, не система органов, скелетов или эволюция конечностей.

## Что теперь развивается само

- **Пищевая цепь:** растения → травоядные → хищники → останки → питательные вещества.
- **Почва и растительный покров:** разложение улучшает плодородие; истощение пищевого запаса сдерживает покров и способствует деградации почвы. Восстановление пищи зависит от локального климата, плодородия и покрова.
- **Сукцессия:** при подходящих климате и запасах пищи растительный покров постепенно нарастает; при истощении и неблагоприятном климате редеет. Это не декоративное переключение по таймеру поколения.
- **Биомы:** океан, берег, холодные области, сухие земли, луга, леса, влажные низины и возвышенности. Их состояние рассчитывается из климата, рельефа и живого покрова.
- **Влияние среды на выживание:** покров смягчает температурную нагрузку на организм. Организмы, пища, останки и среда связаны обратными связями.
- **Естественный отбор:** наследуются и мутируют нейросетевые веса, скорость, размер, обзор, комфортная температура, вытянутость и панцирь. Большое тело, высокая скорость и дальний обзор имеют энергетическую цену.
- **Расселение:** долгота замкнута. Существо и его сенсоры переходят через шов карты, а не упираются в невидимую стену. Широта ограничена; точная геодезическая физика на сфере не моделируется.

В статистике видны лесистость, плодородие, число заселённых участков, биомасса, поколения, популяции двух типов питания и причины смерти. Возможны рост, спад, исчезновение хищников и полное вымирание. Баланс не гарантируется скрытым подселением животных.

### Что является визуализацией, а что моделью

Рельеф и объекты отображаются в **настоящей 3D-сцене**, с перспективной камерой, освещением, материалами, небом и облачной оболочкой. Используются процедурные шейдеры и MultiMesh, а не набор скриншотов.

Экология при этом рассчитывается на **сетке 80 × 48 участков**, замкнутой по долготе. Леса — агрегированный растительный покров; конусообразные растения показывают его, а не являются отдельными деревьями с нейросетями. Облака, звёзды, мелкая фактура и покачивание отростков — графические эффекты. Планета и организмы имеют **условный игровой масштаб**: это не Земля в километрах и не физическая микроскопия в микрометрах. Приближение не создаёт новые микробы из ничего.

Ускорения 2× / 5× / 10× увеличивают число шагов, а не отключают взаимодействия. При нагрузке скорость ограничивается процессором. Пауза замораживает автономные шаги и затухание тепла; кисти и одиночный шаг остаются доступны. Косметическая анимация может продолжаться.

## Нейросети

У каждого организма индивидуальная сеть **16 → 8 ↺ → 4**, **236 весов и смещений**, `tanh`. Восемь скрытых значений с прошлого шага влияют на следующий. Это короткое числовое состояние, не текстовые воспоминания.

Входы: энергия, локальная пища, пища в четырёх направлениях, суша/вода в этих направлениях, температурная нагрузка, исследовательский сигнал, направления к ближайшей добыче и угрозе. Выходы: движение X/Y, готовность есть/атаковать и размножаться. Рождение также требует подходящих возраста, энергии и здоровья.

Начальные сети содержат **наследуемые предрасположенности** к поиску пищи, охоте и уходу от угрозы. Эти связи мутируют вместе с другими весами. Нельзя утверждать, что всё поведение само обучилось с нуля. Теперь внутри жизни обучается отдельный индивидуальный выходной слой; наследуемые рекуррентные веса не перезаписываются. См. раздел «Интеллект каждого существа». Потомки не наследуют ранения, текущую память и число охот. Тип питания пока наследуется без переключения мутацией.

Восемь столбиков в карточке — реальные состояния выбранной сети. Это нейроэволюция и небольшое индивидуальное обучение с подкреплением, не сознание, LLM или планировщик цивилизаций. Перехода к разумным обществам пока нет.

## Движение и наблюдение за поведением (этап 1 из 5)

Микроорганизмы сохраняют уменьшенный в четыре раза размер. Тело плавно поворачивается к фактическому направлению последнего движения, по короткой дуге угла. Направление берётся из измеренного смещения, в том числе через шов долгот, а не назначается случайно. При остановке сохраняется последний курс. Сила и частота движения жгутиков зависят от измеренной скорости; на паузе фаза анимации не меняется. Это визуализация существующей модели, не новая система движения или обучения.

Выбери организм и открой **«Аналитика и организм»**. В прокручиваемой карточке показаны:

- действие, энергия, здоровье и восемь действительных состояний рекуррентной памяти;
- день последнего решения, замеченные на тот момент добыча/угроза и измеренная скорость по X/Y;
- **все 16 входов** последнего вызова сети: нормализованная энергия, пища здесь и в четырёх направлениях, суша/океан в этих направлениях, температурное отклонение, случайный сигнал, относительные сигналы добычи и угрозы;
- **все 4 выхода**: движение X/Y, питание, размножение; отдельно отмечено, заблокировал ли берег движение.

Входы — **сигналы на момент решения**, а не повторно вычисленные показания после движения. X растёт на восток, Y — на юг. Векторы добычи/угрозы ослабевают с расстоянием и нулевые, если цель не замечена. Номер замеченной цели может относиться к существу, погибшему позже в том же последовательном шаге. Это не утверждение, что существо «понимает» мир или сознательно выбрало цель.

Положительный сигнал не гарантирует результат: питание допускается при выходе > −0.4, размножение — при > −0.5, но нужны также доступная пища либо подходящие возраст, энергия, здоровье и свободное место в популяции. Надписи «Спасается»/«Охотится» теперь требуют измеренного движения от замеченного хищника / к добыче; само наличие соседа больше не выдаётся за преследование. Фактическое питание, атака и размножение по-прежнему имеют приоритет в подписи действия.

Новорождённым и старым сохранениям без наблюдений не придумывается прошлое решение: карточка сообщает, что нужен первый шаг. Наблюдения хранятся отдельно от наследуемых признаков как необязательные проверяемые метаданные **сохранения v8**; ручная загрузка, восстановление автокопии и отмена возвращают их вместе с миром. Они не потребляют RNG и не меняют выходы нейросети. Графическая фаза и камера по-прежнему не сохраняются.

Этап 2 добавлен ниже. По уточнённому запросу пользователя обучение при жизни из этапа 4 сделано раньше органов. Этапы **3)** наследуемые органы с ценой и **5)** история особей / дерево родства пока не реализованы; расширенная память и долгосрочное обучение также остаются дальнейшими задачами.

## Разные корма и пищеварение (этап 2 из 5)

Вместо единого растительного корма теперь есть **трава, листва кустарников и семена**, а также прежние останки для хищников. Это **два агрегированных запаса растений и запас их семян на каждой клетке**, а не тысячи самостоятельных растений с геномами. Существа пока наземные: водоросли и водные пищевые цепочки не добавлены.

- Трава остаётся прежним полем `food`. Листва хранится отдельно в `leaves`, семена — в `seeds`; каждый запас ограничен 0…1 и нулевой в океане. Покров `canopy` — среда/затенение, не дополнительный съедобный запас.
- Листва растёт при подходящей температуре, влажности и плодородии; засуха и холод вызывают потерю листьев. Кустарниковая листва дополнительно затеняет рост травы. Отпад/разложение возвращают часть условного плодородия, причём усвоение зависит от воды.
- Семена производятся сезонно за счёт части листовой биомассы и постепенно разлагаются. Это заданный сезонный цикл, **не опыление, расселение или полная ботаника**. Баланс воды/питательных веществ не замкнут физически.
- У существ есть наследуемый признак **пищеварения 0…1**. Ближе к 0 лучше усваивается трава, ближе к 1 — листва, середина лучше использует семена. Это торговля преимуществами, не универсальный бонус. У основателей есть вариация, потомки наследуют признак с ограниченной мутацией. Хищники не превращаются в травоядных: для их питания этот признак не используется.
- Входы сети о пище теперь учитывают **доступную питательную ценность для этой особи**. Размер сети прежний: 16→8→4. Выход «есть» разрешает питание; конкретный корм выбирается простым детерминированным правилом максимальной доступной энергии за укус. **Это правило модели, не выученный выбор нейросети.** Можно съесть менее подходящий корм, если привычного нет.
- Один шаг — один общий бюджет укуса и один выбранный запас. Съеденная масса действительно вычитается; энергия ограничена 185. Охота и останки сохраняются, травоядные останки не едят.

В карточке показаны ген пищеварения, местные запасы, **съеденный на последнем шаге корм, масса и фактическая прибавка энергии до расходов шага**. Надписи «травник / листоед / смешанное питание» — условные диапазоны признака, **не новые виды** и не доказательство возникновения устойчивых экологических ниш.

На карте появились слои **«Листва» / «Семена»**, прежний слой пищи называется **«Трава»**. В микровиде низкие зелёные обозначения показывают траву, более широкие тёмные — кустарниковую листву, золотистые — запас семян. Это представительные обозначения клеточных запасов, не отдельные физические растения/семена; обновление геометрии растительности реже обновления чисел в карточке. Кисть посадки добавляет траву и листву; высушивание сокращает оба запаса и семена; затопление обнуляет их. Отмена и автокопии включают все новые поля.

## Интеллект каждого существа — не ИИ-наблюдатель

**Встроенная бесплатная система работает у каждой подвижной особи**, травоядной и хищной, включая основателей, новорождённых и внесённых кистью существ. API-ключи, подписка, интернет, Ollama, загрузка большой языковой модели и отдельная видеокарта не требуются. Python использует только стандартную библиотеку. Растения пока представлены клеточными запасами, поэтому отдельных «мыслящих растений» здесь нет.

У каждой особи отдельно:

1. **Наследуемая рекуррентная сеть 16→8→4** и восемь состояний памяти — исходные предрасположенности и обработка текущих сигналов.
2. **Индивидуальный обучаемый слой из 100 весов**: четыре выхода × (16 входов + 8 состояний + смещение). Он поправляет команды движения, питания и размножения. Это не общий «мозг на всю планету».
3. **Собственный опыт**: число обновлений, средняя/последняя награда, обученные веса и след незавершённого решения. В карточку передаются только компактные показатели, не все веса каждой особи.

Обучение — ограниченный вариант стохастического policy-gradient: к выходным логитам добавляются небольшие исследовательские отклонения, а после шага веса корректируются по результату относительно скользящей средней награды. Используются нормированные признаки, ограничения обновления/весов и небольшое затухание. После первого шага появляется обратная связь, исследование начинается со следующего решения. Исследовательские сигналы детерминированы существующим случайным входом мира и личным счётчиком; чтение карточки не создаёт новых случайных событий.

**Сигнал подкрепления задан разработчиком**, а не придуман организмом: `(изменение энергии + компенсированная цена рождения) / 12 − потеря здоровья / 25 − 0.35 при блокировке берегом + 0.25 за успешное рождение`, ограниченный диапазоном −1…1. Учитываются реальные расходы движения/температуры, питание и ранения за весь последовательный шаг. Цена рождения компенсируется только в учебном сигнале, **не возвращается в запас энергии**. Это приближённое приписывание результата действиям за один шаг, не точное причинное объяснение и не долгосрочное планирование.

Исходный геном сети не переписывается при обучении. Потомок наследует/мутирует геном и пищеварительные признаки, но получает **новую личную память и нулевой обучаемый слой**, не копию опыта родителя. Никакой удалённой модели, общего запроса на всех или скрытого облачного управления нет.

Открой **«Аналитика и организм»** и выбери особь. Раздел **«ИНДИВИДУАЛЬНОЕ ОБУЧЕНИЕ»** показывает число шагов опыта, последнюю/среднюю обратную связь и норму изменения обучаемого слоя. Эта норма **не IQ и не оценка разумности**. Входы/выходы в карточке — действительные сигналы последнего решения, уже с личной поправкой и исследованием. На паузе/при запросах состояния обучение не идёт.

**Что доказано тестами:** в контролируемой задаче с двумя разными сигналами агент обучается противоположным поворотам; для трёх фиксированных семян средняя ошибка становится меньше 0.15 против 0.6 у замороженной нулевой политики. Разный опыт при одинаковом геноме даёт разные команды. Это **не доказательство**, что любая особь всегда станет умнее или что вся экосистема обязательно дольше проживёт. Гарантии сознания, речи, человеческого интеллекта, цивилизации, запоминания конкретных мест или возникновения целей нет. Сейчас это реактивная адаптивная политика поверх небольшой рекуррентной сети; базовые склонности уже заданы наследуемыми весами.

Камера и её масштаб не входят в экологическую модель.

Файлы **v1–v7 читаются** и преобразуются в v8:

- Для v1–v3 недостающие температурная поправка, число внесённых основателей и ручные смерти инициализируются нулём; существующие поля v4/v5 сохраняются.
- Для v1–v4 добавляются нейтральные признаки тела: вытянутость 1, панцирь 0. Линии восстанавливаются только по доступным родителям; у v5 признаки и линии сохраняются.
- Для v1–v7 каждой особи добавляется собственный включённый обучаемый слой с нулевыми весами/опытом; старые геном, рекуррентная память и RNG сохраняются. Уже выученный опыт из v8 сохраняется полностью.
- Для v1–v6 листва и семена начинаются с нуля, чтобы не удваивать существующую пищу. Существующая трава сохраняется, пищеварение получает нейтральное для прежней травяной диеты значение 0; сеть, её память и RNG не меняются. Новая листва постепенно появляется при подходящих условиях.
- Для v1–v5 влага инициализируется по сохранённым климату и рельефу, а надбавка осадков — нулём, без расходования сохранённого RNG.

Старые веса, текущие существа, память и имеющиеся поля среды сохраняются. Новые экологические правила меняют будущую динамику старых файлов — это не обещание побитово повторить старую версию. Сохранение v8 на той же версии кода/Python продолжает ту же последовательность, что проверяется тестами.

JSON проверяется по типам, диапазонам, размерам, геномам и балансам популяции/смертности. Начальная популяция + рождения + введённые основатели − все смерти = текущая популяция; ручное заселение не выдаётся за естественную эволюцию. Нет `pickle`. Запись атомарная. Неправильный файл не заменяет работающий мир.

Начальный каталог — `user://worlds` Godot, обычно:

- Windows: `%APPDATA%\Godot\app_userdata\Биосфера — эволюция\worlds`.
- Linux: `~/.local/share/godot/app_userdata/Биосфера — эволюция/worlds`.

## Собрать отдельную программу

Исходники и сценарий сборки находятся в репозитории; **готовый проверенный установщик здесь не приложен**.

1. Установи Export Templates **своей версии Godot** через меню редактора.
2. Собирай Windows на Windows, Linux на Linux.
3. Для включения интерпретатора установи PyInstaller, поддерживающий твою версию Python:

```powershell
py -3 -m pip install --upgrade pyinstaller
py -3 tools/build_desktop.py --godot "C:\Programs\Godot\Godot.exe" --bundle-python
```

```bash
python3 -m pip install --upgrade pyinstaller
python3 tools/build_desktop.py --godot /path/to/Godot --bundle-python
```

Результат — `build/Biosphere-Windows/Biosphere.exe` или `build/Biosphere-Linux/Biosphere.x86_64`. С `--bundle-python` рядом будет `core/biosphere-core[.exe]`; интерпретатор у получателя не нужен. Передавай **всю результирующую папку**.

Без `--bundle-python` исходники ядра уже включены в ресурсы программы через ZIP, но у получателя должен быть Python 3.11+. Отдельно запускать его или сервер не нужно. Если упаковщик ещё не поддерживает самый свежий Python, этот вариант остаётся доступен.

## Нестандартный Python и разработка ядра

- `BIOSPHERE_PYTHON` или `--python=/absolute/path/to/python` выбирает интерпретатор.
- `BIOSPHERE_CORE_DIR` явно указывает каталог исходников ядра (репозиторий с `simulator/` или сама эта папка).
- При обычном запуске встроенная копия предпочтительнее старой соседней папки.
- После изменения `simulator/*.py` обнови встроенную копию:

```bash
python3 tools/bundle_core.py
```

Сценарии запуска и сборки делают это автоматически. Тест проверяет, что архив соответствует каноническим исходникам побайтно и воспроизводимо. Архив мал и намеренно хранится в Git: он нужен, чтобы одна папка проекта Godot могла запускаться самостоятельно.

При наличии Godot проверка воспроизводится так:

```bash
python3 tools/render_fixture.py
# Укажи абсолютный путь к созданному snapshot.json:
godot --headless --path godot --script res://tests/desktop_smoke.gd -- --fixture=/absolute/path/snapshot.json
```

Генератор создаёт `snapshot.json` и соседний `snapshot-after.json`: это состояния одной настоящей симуляции до/после вмешательства. Не удаляй второй файл перед нативным тестом.

Для проверки настоящей отрисовки запускай **без `--headless`** и добавь `--screenshots=/absolute/path/screenshots`. В Linux без монитора можно использовать `xvfb-run -a`, как в CI.

### Размер организмов

Визуальный размер организмов уменьшен в **4 раза**: тело, ядро, жгутики, высота над поверхностью и кольцо выделения масштабируются вместе. Расстояния камеры, наследуемый размер и правила симуляции не изменены. На орбите цветные отметки показывают скопления, а не тела отдельных микроорганизмов.
