# Биосфера — настольная игра про эволюцию

**Обычная программа с окном Godot, не сайт.** Браузера, HTTP-сервера, сетевых портов и внешних API нет. Всё работает локально и без интернета.

Задаёшь условия планеты и наблюдаешь, как организмы питаются, размножаются, охотятся, избегают угроз и эволюционируют. У каждого своя наследуемая рекуррентная нейросеть с кратковременным состоянием.

Пока это **2D-прототип искусственной жизни**, а не законченная игра масштаба SAO: здесь ещё нет сознательных NPC, речи, цивилизаций и симуляции настоящей Земли.

## Запуск у тебя на компьютере

Требуются **Godot 4.4 или новее** (обычная версия, не обязательно .NET) и **Python 3.11 или новее**. Можно использовать свежий Python: ядро написано на стандартной библиотеке, без TensorFlow, PyTorch, pip-зависимостей и Python-плагинов для Godot.

1. Сохрани проект целиком. Папки `godot` и `simulator` должны лежать рядом.
2. В менеджере Godot нажми **Импортировать**, выбери **`godot/project.godot`**.
3. Открой проект и нажми **F5**.

**Больше ничего вручную запускать не нужно.** Godot сам находит Python и запускает скрытый дочерний процесс ядра. При закрытии окна ядро завершается. Открывать терминал с сервером или браузер не требуется.

На Windows сначала проверяется `py -3`, затем `python`; на Linux/macOS — `python3`, затем `python`. Старые версии ниже 3.11 отклоняются. Если используется нестандартная установка Python, см. раздел ниже.

### Запуск без открытия редактора

Если Godot находится в PATH:

- Windows: двойной щелчок по **`start_game.bat`**.
- Linux: **`./start_game.sh`**.

Или явно укажи путь к движку:

```powershell
py -3 tools/launch.py --godot "C:\Programs\Godot\Godot.exe"
```

```bash
python3 tools/launch.py --godot /path/to/Godot
```

Портативный Windows-редактор `Godot*.exe` можно положить в корень репозитория: запускатель его найдёт. `tools/launch.py` передаёт приложению путь к тому же Python, которым запущен сам.

## Что улучшено в 0.2

- **Пищевая цепь:** растения → травоядные → хищники → останки → питательные вещества для растений. Хищники не едят растения, травоядные не едят останки.
- **Здоровье и охота:** атаки наносят урон; раненые постепенно восстанавливаются при достаточной энергии, а размножение сильно раненых запрещено. Одна жертва учитывается только один раз, даже при нескольких нападающих.
- **Наследуемые признаки:** скорость, размер тела и дальность обзора. Скорость, большой размер и дальний обзор требуют энергии; размер также влияет на питание и силу атаки.
- **Индивидуальная память:** сеть 16 → 8 ↺ → 4 с восемью рекуррентными состояниями. На решение влияют предыдущие внутренние состояния, а не только текущие входы.
- **Новые ощущения:** направление к ближайшей добыче или угрозе в пределах собственного обзора. Поиск соседей использует пространственные ячейки вместо полного перебора мира для каждого агента.
- **Наблюдение:** травоядные — круги, хищники — треугольники, тяжело раненые выделены красным. У выбранного существа видна граница обзора.
- **Карточка организма:** здоровье, питание, наследственные признаки, родитель, потомки и число успешных охот. Восемь столбиков показывают **реальные состояния памяти** выбранной сети, не декоративную анимацию.
- **Статистика:** отдельные кривые травоядных и хищников, общая численность и причины смертности. На карте добавлен слой останков.
- **Сохранения v2:** здоровье, память, признаки и новые ресурсы сохраняются полностью. Старые сохранения v1 автоматически преобразуются при загрузке.
- **Выход без потери прогресса по ошибке:** при закрытии окна есть выбор «Сохранить и выйти», «Выйти без сохранения» или «Остаться». При ошибке записи программа не закрывается.
- **Клавиатура:** F11 — полный экран, Ctrl+S — сохранить, Ctrl+O — загрузить, пробел — пауза.

Также остались генерация по семени, сезонный климат, управление условиями планеты, выбор существа мышью, ускорения 1× / 2× / 5× / 10× и файловые диалоги самого приложения.

### Параметры планеты

| Параметр | Что означает |
|---|---|
| Семя | Воспроизводимая генерация рельефа и начальной жизни |
| Температура | Базовая температура до сезонных и широтных поправок |
| Осадки | Скорость восстановления растений, от 0.05 до 1 |
| Уровень моря | Порог высоты рельефа, **не процент площади океана** |
| Популяция | Количество первых существ: от 2 до 300 |
| Мутация | Вероятность изменения каждого веса при рождении; также влияет на признаки |
| Доля хищников | Начальная доля от 0 до 0.5; 0.16 — около 16%. Количество округляется до целого |

Нажми **«Создать новый мир»**, чтобы применить параметры. Это заменяет текущий мир; сначала сохрани его, если хочешь продолжить позже. Клавиша **пробел** ставит время на паузу.

Для начала подходят: семя 42, температура 18 °C, осадки 0.65, море 0.42, 90 существ, мутация 0.12, доля хищников 0.16. Технический предел живой популяции — 500. Долю хищников можно установить в 0, чтобы наблюдать только травоядных. При полном вымирании новые существа сами не появляются: измени условия или загрузи сохранение.

## Сохранения

Кнопки **«Сохранить»** и **«Загрузить»** открывают выбор файла `*.biosphere`. Начальная папка — `worlds` в каталоге пользовательских данных Godot:

- Windows: обычно `%APPDATA%\Godot\app_userdata\Биосфера — эволюция\worlds`.
- Linux: обычно `~/.local/share/godot/app_userdata/Биосфера — эволюция/worlds`.

Можно выбрать другую папку. Сохраняются **рельеф, растения и останки, все существа, их здоровье, признаки, нейросетевые веса и текущая память, наследственные связи, время, пауза, скорость, статистика и состояние генератора случайных чисел**. При одинаковых версиях кода и Python загруженный мир продолжает ту же последовательность эволюции; это проверяется тестом.

Формат — версионированный JSON, не `pickle`. Загрузка проверяет размеры массивов, диапазоны чисел, ID, нейросети, историю и состояние случайного генератора. Некорректный файл не заменяет работающий мир. Запись атомарная: сначала временный файл, затем замена, чтобы ошибка записи не уничтожила предыдущее сохранение.

Сохранения **v1** из предыдущей версии читаются автоматически: все старые существа остаются травоядными, 140 старых весов переносятся в расширенную сеть, новые сенсорные и рекуррентные связи обнуляются, память начинается с нуля. Старые причины смерти помечаются как неизвестные, а не приписываются охоте или голоду. Исходный файл не перезаписывается при загрузке; следующее ручное сохранение будет в формате v2. Правила экологии изменились, поэтому продолжение старого v1 не совпадает со старой версией игры.

**Автосохранения пока нет.** Перед закрытием сохрани мир кнопкой или выбери «Сохранить и выйти» в диалоге закрытия. После запуска всегда создаётся стартовая планета; для продолжения выбери «Загрузить».

## Как устроен интеллект

У каждого организма собственная сеть **16 → 8 ↺ → 4**, **236 весов и смещений**, активация `tanh`. Скрытый слой получает 16 входов и восемь своих значений с предыдущего шага. Все нейроны читают одно и то же предыдущее состояние; после расчёта память заменяется одновременно.

**16 входов:** энергия; пища под существом; пища в четырёх направлениях; суша/вода в этих направлениях; разница местной и комфортной температуры; случайный исследовательский сигнал; два компонента направления к добыче; два компонента направления к угрозе. Для хищника пищевые сенсоры показывают останки, для травоядного — растения. Цели за пределами обзора не воспринимаются. Сила направленного сигнала падает с расстоянием. Память содержит восемь чисел от −1 до 1, а не текстовые воспоминания.

**4 выхода:** движение по X, движение по Y, готовность питаться/атаковать, готовность размножаться. Само рождение также требует достаточных возраста, энергии и здоровья. У хищников более высокий энергетический порог и стоимость рождения потомка.

Начальные сети не полностью случайны: в веса заложены **базовые эволюционирующие предрасположенности** к поиску пищи, преследованию добычи и уходу от угрозы. Это часть генома, а не обход нейросети отдельной функцией движения. Эти связи тоже мутируют, поэтому нельзя утверждать, что поведение целиком «само обучилось с нуля».

Потомок получает копию весов с вероятностными мутациями и наследует тип питания, скорость, размер, обзор, комфортную температуру и цвет линии. Питание (травоядное/хищник) пока не меняется мутацией. Состояния памяти, ранения и число охот **не наследуются**. Более удачные стратегии оставляют больше потомства. Цвет помогает отслеживать линии, но не определяет биологический вид.

Это **нейроэволюция с кратковременным состоянием**, а не сознание, языковая модель или обучение градиентным спуском в течение жизни. Нет речи, планировщика цивилизаций и сложного поиска пути вокруг препятствий. Физиология, правила боя и условия рождения запрограммированы; решения движения и питания зависят от индивидуальной сети. Номер поколения сам по себе не означает рост интеллекта.

Экосистема не обязана оставаться в равновесии: возможны всплески хищников, истощение пищи, исчезновение одного типа питания и полное вымирание. Обратная связь возникает из взаимодействий, но параметры являются игровыми, а не биологически откалиброванными.

## Как собрать отдельную программу (.exe / Linux)

В репозитории находятся **исходники и сценарий сборки**, а не уже проверенный установщик. Godot-экспорт без Python-ядра неполон, поэтому используй `tools/build_desktop.py`.

### Подготовка

1. В Godot установи **Export Templates / шаблоны экспорта именно своей версии движка** через меню редактора.
2. Собирай на целевой ОС: Windows-сборку на Windows, Linux-сборку на Linux.
3. Для сборки, работающей **без установленного Python у получателя**, установи PyInstaller:

```powershell
py -3 -m pip install --upgrade pyinstaller
```

Выбранная версия PyInstaller должна поддерживать твою версию Python. Поддержка только что вышедшего Python в упаковщиках может появиться позже; само ядро не зависит от PyInstaller.

### Самостоятельная сборка с включённым Python

Windows:

```powershell
py -3 tools/build_desktop.py --godot "C:\Programs\Godot\Godot.exe" --bundle-python
```

Linux:

```bash
python3 -m pip install --upgrade pyinstaller
python3 tools/build_desktop.py --godot /path/to/Godot --bundle-python
```

Результат:

```text
build/Biosphere-Windows/
  Biosphere.exe             Нативное окно Godot
  core/biosphere-core.exe   Ядро со включённым Python
  START.txt
```

Для Linux аналогичная папка `Biosphere-Linux` с `Biosphere.x86_64` и `core/biosphere-core`.

**Передавать нужно всю папку**, а не только `Biosphere.exe`. На компьютере получателя не требуются редактор Godot, браузер, сервер или отдельно установленный Python, если сборка выполнена с `--bundle-python`. Это настольная программа, не Electron и не веб-обёртка.

### Экспорт с использованием уже установленного Python

Без `--bundle-python` сценарий копирует исходники ядра в `core/simulator`. В этом варианте у получателя нужен установленный Python 3.11+, но он всё равно запускается автоматически и без отдельного терминала. Это удобно для разработки на самой свежей версии Python, если упаковщик её ещё не поддерживает.

## Если ядро не запускается

Окно показывает ошибку, а кнопка **«Перезапустить ядро»** позволяет повторить запуск после исправления причины.

Если Python установлен не в PATH, задай `BIOSPHERE_PYTHON` полным путём или передай аргумент после `--`:

```powershell
$env:BIOSPHERE_PYTHON = "C:\Path\To\Python\python.exe"
# Затем запусти Godot/программу из этого окружения.
```

```bash
godot --path godot -- --python=/absolute/path/to/python3
```

Параметр содержит путь **к исполняемому файлу**, без дополнительных флагов. Для готовой сборки с `core/biosphere-core` системный Python вообще не используется.

## Архитектура

```text
Нативное окно Godot / GDScript
           │
           │ приватные stdin/stdout-каналы ОС, JSON-строки
           ▼
Дочернее Python-ядро
  климат → растения → индивидуальные сети → отбор
```

Godot сам владеет процессом. Приватный протокол обновлён до v2; устаревшее ядро отклоняется с понятным сообщением о необходимости пересборки, а не используется с несовместимой схемой состояния. Чтение каналов неблокирующее, ответы собираются из фрагментов; команды выполняются последовательно. При нормальном закрытии отправляется команда выхода, затем при необходимости процесс завершается принудительно. При закрытии входного канала ядро выходит само. В каждом экземпляре программы свой мир.

Шаг модели — 0.25 условного дня. Окно запрашивает шаги примерно раз в 0.1 секунды; при 1× это до 2.5 дней в секунду, при достаточной производительности. На паузе физиология и растения не обновляются. Под нагрузкой симуляция замедляется, а не выполняет бесконечное догоняющее количество шагов.

```text
godot/main.gd             Нативный интерфейс, параметры, файлы и управление
godot/python_bridge.gd    Поиск Python, запуск, каналы, завершение
godot/world_view.gd       Карта и выбор организма
godot/population_chart.gd Три кривые популяции
godot/neural_activity.gd  Реальные состояния памяти выбранной сети
godot/export_presets.cfg  Экспорт Windows/Linux
simulator/world.py       Экосистема, геном и сеть каждого существа
simulator/runtime.py     Команды модели без сети и фонового сервера
simulator/worker.py      Закрытый протокол между процессами
simulator/persistence.py Полное сохранение и проверка загрузки
tools/launch.py          Запуск нативного окна без редактора
tools/build_desktop.py   Сборка программы и Python-ядра
tests/                  Модель, сохранения и реальные дочерние процессы
```

## Проверки и текущий статус

```bash
python3 -m unittest discover -s tests -v
python3 -m compileall -q simulator tools tests
```

На Windows используй `py -3` вместо `python3`.

Локально проходят **42 теста**: воспроизводимость, наследование и мутации, поколения, вымирание, ограничения, пауза/скорость, сохранение с точным продолжением, защита старого файла при ошибке записи, повреждённые файлы, реальные запросы дочернему процессу, Unicode-пути, выход по команде и завершение при закрытии stdin. Добавлены проверки реального влияния рекуррентной памяти на решение, охоты без двойного учёта жертв, пищевых ограничений, разложения останков, точности пространственного поиска, новых наследственных признаков, сохранений v2 и преобразования старых геномов v1.

Здесь проверки выполнены на Python 3.11. CI настроен также на текущий стабильный Python (`3.x`); запуск именно на самой новой версии локально не подтверждён. Синтаксис GDScript проверен, **полный запуск окна Godot и экспорт .exe в этой среде не проверены**: движок и шаблоны экспорта здесь недоступны. Наличие сценария сборки не означает, что готовый бинарник уже протестирован.

## Дальше к более живому миру

1. Разные растения, специализация питания и более сложные пищевые сети.
2. Вода как ресурс, биомы, болезни и изменение среды самими организмами.
3. Обучение в течение жизни, долгосрочные цели и проверяемые метрики адаптации.
4. Общение, отношения, стаи, поселения и экономика.
5. Затем — редкие высокоуровневые решения и диалоги важных NPC через локальную LLM, отдельно от быстрой экологической симуляции.

Большую модель не нужно вызывать у каждого организма каждый кадр. Маленькие индивидуальные сети подходят для массового поведения; речь и социальное планирование — отдельный следующий уровень.
