# Копия мира с тремя Oxyblob

Файл: **World-9200-Oxyblob-copy.save**

## Загрузка

1. Не удаляй исходное сохранение и его резервную копию.
2. В Sandustry открой «Загрузить игру» → «Импортировать сохранение».
3. Выбери файл `World-9200-Oxyblob-copy.save` (это сохранение, не мод).
4. В списке миров выбери **«Мир №9200 — Oxyblob (копия)»**.
5. Загрузи сохранение **«Тест: добавлены 3 Oxyblob»**.

Для копии создан новый ID мира и новый ID сохранения. Импорт не должен заменить исходный мир: в проверенном коде игры файл выбирается по ID из заголовка, и он отличается от исходного. При ошибке импорта не удаляй оригинал — пришли сообщение об ошибке.

Исходник: свежий экспорт, загруженный 25 октября в 19:12 по местному времени; контрольная сумма MD5 `26d36807fcd08e811b25cdf2dbc95fde`.

Проверено: распаковка/обратная упаковка, уникальность ID, структура новых записей, свободное пространство и отсутствие запретной зоны в выбранных местах, полное сравнение остальных данных. Поведение добавленных записей проверено функциями вида из кода 0.6.0 на имитированных входных данных. **Реальный импорт и запуск игры не проверены.**
