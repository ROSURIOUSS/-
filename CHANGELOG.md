# Изменения

## 2.3.1 — «Мастер стал умнее»

- Ответ модели теперь чинится, а не выбрасывается: markdown-ограждения, текст вокруг JSON,
  обёртки `{scene:…}`, «сырые» переводы строк внутри строк и обрыв по лимиту токенов.
  Если JSON развалился совсем, проза всё равно спасается — резервный рассказчик не включается.
- Обрыв ответа по `finish_reason=length` — повтор той же модели с увеличенным бюджетом,
  а не переход на слабую запасную.
- Для «думающих» моделей (Gemini 2.5, o3/o4, DeepSeek R1, Qwen3) запрашиваются минимальные
  размышления: сцены приходят быстрее и не остаются пустыми.
- Промпт: мастер получает хвост последней сцены и продолжает с него, а не начинает историю заново.
  Добавлены запрет на штампы, требование конкретных вариантов и обязательный русский язык.
- В панели «Мастер» можно выбрать модель из живого каталога OpenRouter — платную или бесплатную.
  Выбор сохраняется в `data/settings.json` и применяется без перезапуска.
- Панель показывает последний успешный ответ (модель, время, починку формата) и последний сбой.
- Под композером видно, кто написал сцену и сколько это заняло; в резервном режиме — причину.
- Дневной лимит и ошибки модели больше не теряются в общем тосте.

## 2.3.0 — «Больше миров, больше памяти»

- Три новых мира: морская хтонь «Тихий прилив», дизельпанк-вестерн «Мёртвый поезд»
  и дворцовая интрига «Стеклянный двор». У каждого — своя система проверок (d20 / 2d6 / d100),
  четыре правила, стартовая сцена и три варианта открытия, свой акцентный цвет и обложка.
- Четыре новых архетипа: Охотник, Контрабандист, Служитель и Механик — со своими
  характеристиками, снаряжением, зацепкой для мастера и портретом. Всего девять классов.
- Новые черты и бремена: «Твёрдая рука», «Дурное предчувствие», «Тихий шаг», «Крепкая шкура»;
  «Клеймо», «Под наблюдением», «Голод». Больше сочетаний — разные истории.
- Живой архив: карточки с обложкой, уровнем, числом ходов и активными заданиями; поиск
  по герою, миру и жанру; фильтры «все / живые / погибшие»; сортировка по свежести,
  длине и имени. Отсюда же ветка после смерти, хроника в Markdown, выгрузка и импорт.
- В листе героя — вкладка «Ходы»: оглавление истории с исходами бросков, клик возвращает к сцене.
- В шапке сцены — компактный HUD (HP, энергия, золото, уровень, рывок) и метка «сохранено»,
  которая вспыхивает после каждого хода.
- Экран выбора мира показывает незаконченные истории, число миров и систем; на главной
  появилась кнопка «Случайный мир».
- Экран героя перестроен под девять архетипов: крупные портреты, характеристики и зацепка.
- Подсказка «?» с горячими клавишами, кнопка «вниз» для длинных сцен, аккуратная мобильная сетка архива.
- Миграция сохранений больше не знает фиксированный список портретов: новые классы подхватываются сами.

## 2.2.3 — «Мастер на связи»

- Панель «Мастер» в игре: видно, какой ключ и модель используются, откуда взят ключ,
  когда был последний сбой и почему. Кнопка «Проверить связь» делает настоящий запрос
  к OpenRouter и показывает ответ по каждой модели.
- Ключ можно вставить прямо в приложении — без редактирования `.env`. Он хранится
  в `data/settings.json`, главнее `.env`, и применяется сразу, без перезапуска игры.
- Если на ключе нет кредитов (402), сервер сам подставляет бесплатные модели из живого
  каталога OpenRouter, а не из устаревшего списка.
- Ошибка модели больше не тонет: её текст показывается игроку и пишется в журнал аудита.
- Общий бюджет ответа — 70 секунд: вместо десяти минут перебора моделей игрок быстро
  получает либо сцену, либо понятную причину и резервного рассказчика.
- `npm run doctor` больше не ссылается на «песочницу» и подсказывает панель «Мастер».

## 2.2.2 — «Приложение по умолчанию»

- `npm start` теперь запускает приложение с окном, а не веб-сервер: браузер больше не нужен.
  Для отладки в браузере — `npm run serve` (он же `npm run start:web`).
- Окно запоминает размер, положение и развёрнутость между запусками (`window.json`).
- Повторный запуск не поднимает второй сервер: окно уже запущенной Лории выходит вперёд.
  Флаг `--new` открывает ещё один экземпляр.
- Профиль WebView2 перенесён в папку сохранений — окно работает и из read-only каталогов.
- Если WebView2 не установлен, в лог пишется понятная причина и ссылка на установщик.
- Запасное окно Edge/Chrome (`--app`) получило отдельный профиль и больше не похоже на браузер.
- В окне появилась своя иконка в панели задач.
- Длинные истории: последние 60 ходов сразу, остальные догружаются по 30 через `/api/games/:id/turns`.
- Поле действия помнит прошлые вводы (`↑`/`↓`), варианты выбираются клавишами `1`–`4`.
- В журнале заданий — счётчик активных и сортировка: сначала текущие.

## 2.2.1 — «Сборка без прав администратора»

- `npm run build:exe` на Windows больше не пытается изменить `node.exe` прямо в
  `C:\Program Files\nodejs` (там нужен администратор). Скрипт копирует его в `build\`
  и работает с копией.
- Если иконку и свойства файла поставить не удалось, сборка продолжается без них.
- Понятная ошибка, если `release\Loria.exe` запущен и файл занят.

## 2.2.0 — «Своё окно»

- Лория стала настольным приложением: игра открывается в собственном окне WebView2
  (`@webviewjs/webview`), без адресной строки, вкладок и меню браузера.
- Откат, если нативное окно недоступно: Edge/Chrome в режиме `--app`, затем обычный браузер.
- При запуске двойным кликом служебная консоль больше не появляется; лог — в `loria.log`.
- Флаги `--web` (открыть в браузере) и `--console` (оставить консоль с логами).
- В сборку добавляется нативный модуль окна; `.exe` вырос со 101 до 105 МБ.
- Если приложение не смогло стартовать в скрытом режиме, показывается окно с ошибкой.

## 2.1.1 — «Двойной клик»

- `Лория.bat` — запуск игры одним кликом: проверка Node (18+), свободный порт, браузер,
  окно не закрывается молча при ошибке. `Лория.bat --exe` запускает собранный `Loria.exe`.
- `Собрать EXE.bat` — установка инструментов и сборка `release\Loria.exe` без командной строки.
- Лаунчер больше не требует `node:sea`: на Node 18 игра просто работает как обычный сервер.

## 2.1.0 — «Один файл»

**Новое**
- `Loria.exe` — автономная сборка для Windows: Node, сервер и вся графика в одном файле,
  без установки. Запуск двойным кликом, браузер открывается сам.
- `npm run app` — настольный запуск из исходников: выбирает свободный порт, распаковывает
  статику, открывает браузер, читает `.env` рядом с лаунчером.
- Гарантированное место для сохранений и сессий бота: `LORIA_DATA_DIR`, по умолчанию `data/`
  рядом с игрой или `%LOCALAPPDATA%\Loria`, если папка только для чтения.
- Необязательный запуск Telegram-бота вместе с настольной версией (если задан токен).

**Мелочи**
- Компактный HUD (здоровье, энергия, опыт) в шапке сцены на узких экранах.
- Лист героя помнит, где ты уже был.
- `Esc` закрывает и лист героя, и всплывающие окна.
- `npm run build:exe` собирает иконку, свойства файла и релиз под Linux.


## 2.0.0 — «Два интерфейса»

**Новое**
- Telegram-бот (`npm run bot`) на том же движке: кнопки вариантов, свободный текст, голосовые
  (распознавание через OpenRouter), отмена хода, рывок, `/hero`, `/audit`, `/export`, `/new`.
- Общий движок `server/engine.js` для веба и бота; `server/index.js` стал тонким HTTP-слоем.
- Два новых мира: «Лес, который слушает» (славянский фольклор) и «Соляная пустошь» (постапокалипсис).
- Портреты пяти архетипов в конструкторе, превью и листе героя.
- Рывок: второй серверный бросок за ход, восстанавливается передышкой.
- Передышка: энергия → здоровье без запроса к модели.
- Опыт и уровни: награда за выживание, выбор улучшения с серверной проверкой списка.
- Отмена хода: два снимка состояния, откат сцены целиком.
- Ветка после смерти: копия истории, в которой герой возвращается с полпути.
- Перенос историй: сохранение в JSON и импорт на другом устройстве.
- Страница «Правила» с таблицей запретов для мастера.
- Сводка «Ранее в истории» на длинных партиях.
- PWA: манифест, иконки, офлайн-оболочка, установка на телефон.
- Миграция старых сохранений, лимиты на создание историй, заголовки безопасности.

**Качество**
- `npm test` — 30 юнит-проверок движка.
- `npm run bot:test` — 11 проверок Telegram-бота без сети (миры, голос, отмена, экспорт).
- `npm run e2e` — 15 сквозных проверок через мок-OpenRouter (весь ИИ-путь без сети и трат).
- Настраиваемые лимиты: запросы в сутки, создания историй в час, пауза между ходами.
- Dockerfile, docker-compose (веб + бот), healthcheck.
- Более настойчивый разбор ответов модели: повтор со строгим промптом, если JSON не разобрался.
- Понятная диагностика `npm run doctor`: 401, 402, 404, отсутствие сети, прокси.
